# Схемы Room

`com.corriente.data.db.AppDatabase/N.json` — экспорт схемы версии N (ARCHITECTURE.md ADR-008, I-20);
на них строится `AppDatabaseMigrationTest` (`MigrationTestHelper`).

* **1, 2, 6** — настоящий экспорт Room (`identityHash` — реальный).
* **3, 4, 5** — собраны вручную вместе с миграциями (`identityHash: placeholder…`): в момент их
  написания среда не экспортировала схемы. Структура сверена с настоящей 6.json по цепочке миграций
  (`migrateAll_thenOpenWithRoom`), но «побайтового» экспорта Room у них нет.

**Как получить новую схему.** Room (плагин `androidx.room`) пишет `N.json` только если такого файла ещё нет
в `schemas/`. Поэтому при повышении версии БД достаточно собрать модуль (`./gradlew :core:data:kspDebugKotlin`) —
появится `N+1.json`. Если нужно перегенерировать существующий файл (например, после правки сущностей без
повышения версии — что делать нельзя, но для сверки), удалить его, собрать с `--no-build-cache`.
